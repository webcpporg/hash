== Changelog

What changed in hash in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#hash-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added the library.
* Added Boost.Hash2's algorithms and HMAC under webcpp::hash's names.
* Added keccak_256, Ethereum's Keccak-256, over XKCP's permutation.
* Added blake3, BLAKE3 with keyed hashing, key derivation and its extendable output.
* Added HKDF (RFC 5869) over every Boost.Hash2 hmac, on backends::hash2.
* Added PBKDF2 (RFC 8018) over every Boost.Hash2 hmac, on backends::hash2.
* Added backends::bearssl, BearSSL's HKDF over MD5, SHA-1 and SHA-2 (hkdf alone).
* Added backends::sodium: HKDF (RFC 5869) over libsodium's HMAC-SHA-256 and HMAC-SHA-512.
* Added backends::openssl, OpenSSL 3.5.9's HKDF and PBKDF2, through /webcpp/hash//openssl on native, wasip2 and wasip3, refusing lengths past OpenSSL's int.
* Added bench/pbkdf2_sha512.cpp and doc/performance.adoc: PBKDF2-HMAC-SHA-512 at 1,000,000 iterations measured on every backend and target, with the data in doc/measurements.throughput.json.
* Added argon2id (RFC 9106, one lane) on backends::sodium, with libsodium's three presets.
// end::unreleased[]
