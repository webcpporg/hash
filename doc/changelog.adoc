== Changelog

What changed in hash in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#hash-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added the library, with Boost.Hash2's algorithms and HMAC under webcpp::hash's names, and every function that returns boost::system::result `+[[nodiscard]]+`.
* Added keccak_256, Ethereum's Keccak-256 over XKCP, and blake3, BLAKE3 with keyed hashing, key derivation and its extendable output.
* Added HKDF (RFC 5869) and PBKDF2 (RFC 8018) over every Boost.Hash2 hmac, on backends::hash2.
* Added argon2id (RFC 9106, one lane) with libsodium's three presets, and scrypt (RFC 7914), on backends::sodium.
* Added backends::sodium's HKDF over HMAC-SHA-256 and HMAC-SHA-512, BLAKE2b with key, salt, personalisation and length, SipHash-2-4, SipHash-2-4x and blake2b_subkey, and backends::bearssl's HKDF over MD5, SHA-1 and SHA-2 (hkdf alone).
* Added backends::openssl, OpenSSL 3.5.9's HKDF, PBKDF2 and digests (SHA-1, SHA-2, SHA-3, SHAKE, Keccak, BLAKE2, RIPEMD-160, MD5-SHA1, SM3) through /webcpp/hash//openssl on native, wasip2 and wasip3, by name.
* Added the default backend, hash2 for key derivation and sodium for argon2id and scrypt, and doc/capabilities.json, the capability table naming each function's default.
* Added the measured tables (doc/measurements.*) from release builds, a reference of 2026-11-16 that decides nothing, and allocation tests: none in hash's code.
* Added the guide: chapters per family and per use case, an example per section, generated tables and llms.txt, and a Boost.Hash2 proposal of keccak_224 to keccak_512.
* Added the families digest_of, hasher, mac and argon2 over digests, macs and kdfs tags, each with a default backend, on hash2, xkcp and blake3, and error::invalid_state.
// end::unreleased[]
