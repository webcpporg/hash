== Changelog

What changed in hash in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#hash-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added the library.
* Added Boost.Hash2's algorithms and HMAC under webcpp::hash's names.
* Added keccak_256, Ethereum's Keccak-256 over XKCP, and blake3, BLAKE3 with keyed hashing, key derivation and its extendable output.
* Added HKDF (RFC 5869) and PBKDF2 (RFC 8018) over every Boost.Hash2 hmac, on backends::hash2.
* Added argon2id (RFC 9106, one lane) with libsodium's three presets, and scrypt (RFC 7914), on backends::sodium.
* Added backends::sodium's HKDF over HMAC-SHA-256 and HMAC-SHA-512, and backends::bearssl's over MD5, SHA-1 and SHA-2 (hkdf alone).
* Added backends::openssl, OpenSSL 3.5.9's HKDF and PBKDF2 through /webcpp/hash//openssl on native, wasip2 and wasip3, refusing lengths past OpenSSL's int.
* Added the default backend's profiles (WEBCPP_HASH_PROFILE_FASTEST, _SMALLEST, _PORTABLE, _BACKEND_<NAME>, webcpp's WEBCPP_PROFILE_*), choosing per function among the backends that have it.
* Added the per-algorithm overrides WEBCPP_HASH_DEFAULT_BACKEND_<ALGORITHM>_<NAME>, of HKDF, PBKDF2, argon2id and scrypt, and the capability table doc/capabilities.json.
* Added the measured PBKDF2-HMAC-SHA-512 throughput (doc/performance.adoc) and the allocation tests: none in hash's code, the C libraries' stated (doc/allocation.adoc).
// end::unreleased[]
