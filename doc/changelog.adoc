== Changelog

What changed in hash in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#hash-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added the library.
* Added Boost.Hash2's algorithms and HMAC under webcpp::hash's names.
* Added keccak_256, Ethereum's Keccak-256, over XKCP's permutation.
* Added blake3, BLAKE3 with keyed hashing, key derivation and its extendable output.
* Added HKDF (RFC 5869) over every Boost.Hash2 hmac, on backends::hash2.
* Added PBKDF2 (RFC 8018) over every Boost.Hash2 hmac, on backends::hash2.
// end::unreleased[]
